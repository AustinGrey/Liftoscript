# Gyms

Some workout plans require movements which are easier in some locations than others. We track
locations that offer advantages and call them "gyms" no matter what they might actually be.

E.g. you might need a running track, but whether you get that from a gym, or from running on a trail both places are considered gyms, with the track in question being the equipment it offers.

Defining what a gym is, and business logic which can act on gyms without knowledge of other concepts
belongs here.
