# Quantities

This is a library and code for working with values that have 0+ units associated with them.

unitmathfork/
- This is my fork of the unitmath library (https://github.com/AustinGrey/UnitMath), which has been extended to allow "%" as a valid unit.
- This fork isn't published as an npm package yet cause I didn't want to have to deal with that, so instead I copied the ts files that make it up into this folder.
